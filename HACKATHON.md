## Selected problem statement

Problem 04 — Published Package vs Source Code Integrity Analyzer.

## Project

Vajra compares published npm packages with their source code, flags suspicious changes, and provides evidence-backed explanations.

## AI models used and selection rationale

Product models used at this initial commit: none. Implementation has not started, so no product model has been selected or integrated.

The product will integrate an open-source or open-weight model to contextualize package/source differences and explain findings against validated evidence. Its exact model identity, runtime, and selection rationale will be recorded through a pull request once selected and verified. Meaningful model integration remains required before submission.

## AI coding assistants

OpenAI Codex has assisted with planning, documentation, and repository setup. It was chosen to support code-oriented reasoning, implementation planning, and verification workflows. The underlying model identifier is not independently recorded here; Codex is disclosed as a coding assistant, not as an integrated product model.

Other assistants and product models will be disclosed in the pull requests where they are used.
